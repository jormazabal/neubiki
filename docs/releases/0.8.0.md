# Neubiki 0.8.0

Entrega en preparación para Windows x64 y Android ARM64, desde Android 10. Incorpora papelera y recuperación sin conexión, búsqueda de proyecto, notas manuscritas, edición asistida de varios archivos, reuniones, plantillas, exportación por lotes y copias. La comparación de conflictos utiliza la revisión actual de Proton Drive. El historial de revisiones queda fuera del alcance de esta entrega.

Los clientes 0.6.0 y 0.7.0 instalados desde candidatos locales requieren una primera instalación manual de la versión de distribución compatible. Abrir el instalador sobre la aplicación existente conserva el identificador de paquete y los datos del dispositivo. Las actualizaciones posteriores se consultan desde **Configuración → Actualizaciones**. Los borradores pendientes se protegen antes de ejecutar el instalador.

La firma Tauri autentica Windows en el actualizador. Windows puede mostrar un editor desconocido al abrir el instalador. Android requiere la firma original de Neubiki para conservar la instalación existente y puede pedir permiso para instalar actualizaciones.

El [plan de implementación](../development/neubiki-implementation-plan.md) registra la validación y los requisitos de publicación.
